## 2. 평가 기준과 완료 조건

### 네 평가 기준을 W07에서 어떻게 입증하는가

왼쪽은 주최 측이 공개한 평가 기준이다. 오른쪽은 이 프로젝트에서 심사자가 확인할 수 있는 증거의 예다. 공개 자료에는 항목별 배점, 가중치, 합격선이 제시되지 않았다. [공식 평가 기준](https://axacademy.ai/axwar/samilpwc-1#understand)

| 공식 평가 기준 | 심사에서 확인하는 것 | W07에서 보여줄 증거 |
|---|---|---|
| 기업 운영의 이해와 기획 | 결정권자, 기존 병목, 앞뒤 부서의 목표와 제약, 확장의 필요 | 영업지원의 개별 정산에서 관련자 합산 결재로 넘어간다. 회계는 가용 자금에 따라 지급일이나 조달 계획을 바꾼다. |
| 데이터에 근거한 판단 | 필요한 정보의 정의, 기록 간 관계·시점·한계, 가정 검증 | 원본 3행을 합쳐 3,888,097원을 재현한다. 어느 두 등록 항목이 일치했는지 보인다. 추심 시 입금된 계좌와 실제 지급 수취계좌를 구분한다. |
| 작동하는 운영 시스템 | 앱 안에서 실제 AI가 판단·처리에 기여하는지, 승인이 작업과 상태를 바꾸는지 | AI가 확보·일정조정 대안을 제안한다. 담당자가 선택하면 부서 작업이 생긴다. 회계가 확인한 입금만 부족액 계산에 반영한다. |
| 변경과 예외에 대한 대응 | 정정·정보 부족·거절 뒤의 재검토, 보류, 대안이나 후속 작업 | 승인 뒤 정보가 바뀌면 이전 결재 근거와 변경 내용을 비교한다. 수취계좌가 미확인인 지시는 전송을 보류한다. |

### 제출 가능한 상태를 결정하는 다섯 조건

| 완료 조건 | 확인 방법 |
|---|---|
| ① 실행되는 시스템 | 사건을 입력하고 조회·판단·승인·처리를 거친다. 처리 뒤 저장된 상태를 다음 조회나 결정에서 다시 사용한다. 외부 승인·발주·은행 회신은 모의 처리할 수 있다. |
| ② 세 상황 시연 | 정상 처리, 조건 변경, 정보 부족 또는 승인 거절을 모두 보여 준다. 뒤의 두 상황은 이어서 시연할 수 있다. 조건이 바뀌어도 결론이 같다면 다시 확인한 근거를 보여 준다. |
| ③ 필수 확장 1개 이상 | 참가자의 경험·관심으로 데이터, 조건 또는 예외를 추가하거나 깊게 다룬다. 어느 조회·계산·판단·상태가 실제로 달라졌는지 확인한다. |
| ④ 다른 부서 영향 1개 이상 | 다음 부서가 지켜야 하는 목표나 제약 때문에 선택지·승인·작업·계획 중 하나가 달라져야 한다. 알림을 보낸 뒤 무엇이 달라졌는지까지 확인한다. ③과 같은 사례를 쓸 수 있다. |
| ⑤ 원본과 가정 구분 | 원본은 보존한다. 추출·정제·합성·확인 요청을 구분한다. 새 입력의 근거와 적용 시점을 남긴다. |

언어, 프레임워크, 코딩 도구와 앱 안의 AI 모델은 자유다. 개발 중 코딩 도구를 사용한 기록과, 완성한 앱 안에서 AI가 수행한 일은 각각 다른 증거다. 차트·권고문·기획서는 판단을 설명할 수 있지만, 승인 뒤 후속 작업과 상태가 바뀌는 과정까지 입증해야 한다. [공식 완료 조건](https://axacademy.ai/axwar/samilpwc-1#done) · [설계 가이드 A03](../01_참가자_배포용/A03.html)

공식 예시인 W03에서는 품질팀이 고객 클레임과 배치의 확정 불량률을 확인한다. 기준을 충족하면 품질위원회가 회수를 의결하고 영업·생산이 공급 복구를 처리한다. 미확정 보도가 들어오면 품질 근거를 다시 본다. 출하처를 특정할 수 없으면 담당자에게 확인 작업을 남긴다. W07에서도 같은 방식으로 **입력 → 판단 근거 → 사람의 결정 → 달라진 업무 상태**를 추적할 수 있다. [공식 업무 예시](https://axacademy.ai/axwar/samilpwc-1) · [W03 배포 원문](../01_참가자_배포용/세계관_BPMN/W03.html)

### 파일을 해석할 때 지킬 조건

- 배경 자료 기간은 2024년 1월~2026년 6월이다. 파일별 관측기간은 다르다. 전망·계약 기한은 가상 기준일인 2026년 7월 1일 이후도 포함할 수 있다. 사건 발생일과 업무 적용일을 분리한다.
- CSV는 UTF-8이며 첫 행이 열 이름이다. 구분자는 `|`이다. 기본 금액은 원화·부가세 제외다. 외화 계약·단가·환율 열은 해당 통화와 적용일을 따른다. 제품은 EA, 원료는 kg이다. `NONE`은 해당 없음으로 0과 다르다.
- 주는 월요일에 시작한다. 기본 영업일은 월~금이다. 공휴일은 설정하지 않았다. 달력을 바꾸면 시나리오 가정으로 명시한다.
- 재고·현금·손익은 회사 전체 규모다. 마케팅 주문·쿠폰·반품·광고비·유입·예산기안은 대표 표본이다. 표본 성과를 전사 매출과 합산하거나 연간 예산에 곱하면 전사 효과를 입증할 수 없다.
- SKU, 제품군, 생산 배치, 원료 로트, 공장, 라인은 집계 단위가 다르다. 이름이 유사해도 업무 관계와 수량 대응은 따로 검증한다. 참가자가 보완한 자료에는 식별자·적용 시점·원본 연결·생성 이유를 남긴다. [A05](../01_참가자_배포용/A05.html)

| 지표·통제 | 계산 또는 적용 기준 |
|---|---|
| 순매출·공헌이익 | GMV에 쿠폰이 이미 반영돼 있다. 순매출 = GMV − 반품환불액. 공헌이익은 순매출에서 제품원가, 마케팅비, 채널수수료, 출고·반품 물류비를 각 한 번 차감한다. 주문 행에 수량이 없어 원가 적용 단위와 환불 시 회수 여부를 명시한다. |

| 현금·차입약정 | 기초 현금 + 예정 회수 − 예정 지급 − 기타 유출. 매입채무에 들어간 발주대금을 한 번 더 빼지 않는다. Masil 단독 일말 현금이 영업일별 30억 원 미만이 될 구간을 먼저 찾고, 그 구간 유출 신규 약정은 상위 승인을 받는다. |

### 시연 영상과 재제출

1. 소개 약 30초에 선택 업무와 결정권자를 밝힌다.
2. 정상 사례를 입력한다. 조회한 근거, 계산·AI 판단, 사람의 승인, 생성된 작업이나 상태를 보여 준다.
3. 조건을 바꾼다. 재검토 결과와 이전 판단과의 차이를 보여 준다. 결론이 같으면 유지한 근거를 설명한다.
4. 정보 부족 또는 승인 거절을 재현한다. 확인 요청, 보류, 재상신 또는 대안 선택 중 실제 다음 행동을 보여 준다.
5. 필수 확장과 다른 부서 영향이 앞선 어느 장면에서 쓰였는지 밝힌다. 추가 확장은 보여줄 내용이 있을 때 넣는다.

본인 목소리는 필수가 아니므로 TTS로 해설할 수 있다. 장면별로 실제 동작과 모의 처리를 말로 구분한다. 빨리 감은 구간에는 배속 표시를 넣는다. 얼굴 노출과 편집 방식은 자유다. 설계 이유·데이터 근거는 문항에서 설명할 수 있다. [공식 시연 안내](https://axacademy.ai/axwar/samilpwc-1?tab=submit#video)

## 7. 환경설치, 배포, AI 기록

### 공식 환경설치 4단계

1. **AI 도구 준비.** 실시간 기록 공식 지원 범위를 확인한다. Claude Code는 데스크톱·CLI·VS Code/JetBrains, Codex는 데스크톱·CLI·VS Code, Antigravity는 데스크톱 IDE·CLI를 지원한다. Claude 웹과 ChatGPT Codex 클라우드는 이 실시간 수집 경로에 포함되지 않는다.
2. **프로젝트 폴더 내려받기.** 참가 신청 계정으로 로그인하고 Windows/macOS에 맞는 폴더를 받는다. 루트 README가 있는 폴더를 연다. Windows 배포 README는 긴 경로에서 파일이 누락될 수 있어 짧은 경로에 압축을 풀도록 안내한다.
3. **기록 연결 확인.** 도구에 맞게 프로젝트 설정을 신뢰하고 새 대화를 연다. 미리 켜 둔 도구는 재시작한다. 테스트 프롬프트를 보내고 참가 페이지의 최근 프롬프트에 나타나는지 확인한다. 다른 기기·도구를 사용해도 같은 신청 계정에 기록이 모인다. 운영체제가 바뀌면 해당 버전의 폴더를 다시 받는다. 연결 전 작업은 실시간으로 소급 수집되지 않는다.
4. **배포 방식 선택.** AXHub와 소스 ZIP 중 하나를 고른다. AXHub 설치 도구는 Windows·macOS를 지원한다. 플러그인 공식 지원은 Claude Code·Codex다. Linux·WSL은 원하는 환경에 배포하고 소스 ZIP으로 제출할 수 있다. [환경설치 탭](https://axacademy.ai/axwar/samilpwc-1?tab=setup) · [프로젝트 루트 README](../README.md)
